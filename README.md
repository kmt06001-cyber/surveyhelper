# 네이버 폼 손들기 집계 입력기

교실에서 손들기로 센 인원수를 넣으면, 학생 수만큼 네이버 폼에 응답을 대신 제출하는 사이트예요.
설문 링크만 붙여 넣으면 문항과 선택지를 자동으로 불러와요.

## 인터넷에 올리기 (처음 한 번, 약 10분)

1. **GitHub에 파일 올리기**
   - github.com에 가입하고 로그인해요.
   - 오른쪽 위 `+` → `New repository`를 누르고, 이름(예: `survey-helper`)을 적고 `Create repository`를 눌러요.
   - 화면의 `uploading an existing file` 링크를 눌러요.
   - 압축을 푼 `survey-helper` 폴더 **안의** 파일과 폴더(`api`, `lib`, `index.html`, `generate.js`, `package.json`, `vercel.json` 등)를 모두 끌어다 놓고 `Commit changes`를 눌러요.
2. **Vercel에 연결하기**
   - vercel.com에서 `Continue with GitHub`로 가입해요.
   - `Add New…` → `Project` → 방금 만든 저장소 옆 `Import` → 설정은 그대로 두고 `Deploy`를 눌러요.
   - 1분쯤 뒤 `https://○○○.vercel.app` 주소가 생겨요. 이 주소를 동학년 선생님들께 공유하면 돼요.
3. **접속 코드 정하기 (권장)**
   - 주소를 아는 누구나 아무 네이버 폼에 응답을 보낼 수 있게 되는 걸 막는 장치예요.
   - Vercel 프로젝트 → `Settings` → `Environment Variables`에서 이름 `ACCESS_CODE`, 값은 동학년끼리 정한 코드(예: `1hak2026`)로 추가해요.
   - `Deployments` 탭 → 맨 위 배포의 `…` → `Redeploy`를 눌러야 적용돼요.
   - 선생님들은 사이트의 "접속 코드" 칸에 한 번 넣으면 그 브라우저에서는 기억돼요.

## 쓰는 법

1. 설문 링크를 붙여 넣고 `문항 불러오기`
2. 학생 수 입력 → 객관식은 선택지별 인원(모두 같으면 `전원`), 주관식은 의견을 마침표로 나눠 입력
3. `확인하기` → 문항별 인원 확인 → `제출 시작`

## 알아 둘 점

- 문항별 인원은 정확히 들어가지만, 학생 한 명의 응답 묶음은 무작위로 짝지어져요.
- 객관식(한 개/여러 개 선택)과 주관식(장문·단문)을 지원해요. 날짜, 표 형식 같은 다른 문항이 필수면 제출할 수 없다고 알려 줘요.
- "1인 1회 응답" 설문, 로그인이 필요한 설문은 안 돼요.
- 답에 따라 다른 문항으로 건너뛰는 설정은 따르지 않아요.
- 네이버 폼 내부 방식이 바뀌면 멈출 수 있어요. 그때는 오류 문구를 보고 수정이 필요해요.
- 응답 내용은 어디에도 저장하지 않아요. 학생 이름 같은 개인정보는 넣지 마세요.

## 파일 구성

- `index.html` 화면, `generate.js` 인원수 → 응답지 변환
- `api/survey.js` 문항 불러오기, `api/submit.js` 응답 1건 제출, `lib/naver.js` 네이버 폼 통신
- `test/run.js` 테스트 (`npm test`)
